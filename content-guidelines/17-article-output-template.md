# Article Output Template

Gemma should output finished articles in this structure.

Strategy annotations must not appear inside the publishable article body. Clearly separate editorial metadata, publishable content and editor notes.

```text
# ARTICLE STRATEGY

Primary keyword:
Search intent:
Reader need:
Conversion objective:

# SEO METADATA

SEO title:
Meta description:
Slug:

# ARTICLE

# H1

Introduction...

## H2

...

## Frequently Asked Questions

### Question

Answer

# FINAL CTA

...

# INTERNAL LINK RECOMMENDATIONS

...

# FACT CHECK NOTES

...

# EDITORIAL SCORE

...
```

## Article Strategy

Keep this concise and useful for editors. Include the primary keyword, search intent, reader need and conversion objective.

## SEO Metadata

Provide:

- SEO title.
- Meta description.
- Slug.

Metadata must be accurate and natural.

## Publishable Article

The article body should read naturally. Do not include bracketed instructions, scoring notes, source labels or editorial comments inside the publishable article.

The publishable article should:

- Answer the search query early.
- Use clear headings.
- Include accessibility considerations.
- Avoid unsupported claims.
- Build trust before the strongest CTA.
- Use British English.

## Final CTA

The final CTA should be contextual, phone-led and reassuring. It should give a clear reason to call.

## Internal Link Recommendations

List recommended internal links separately from the article body if exact URLs are not supplied. Include suggested anchor text and the purpose of each link.

## Fact Check Notes

List:

- Facts requiring verification.
- Accessibility claims requiring confirmation.
- External sources needed.
- Unknown information deliberately avoided.

## Editorial Score

Use `14-content-quality.md`. If any mandatory threshold is not met, mark:

```text
STATUS: REVISION REQUIRED
```
